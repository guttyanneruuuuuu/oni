# 人狼鬼ごっこ - Werewolf Tag 3D

3D非対称型マルチプレイヤー鬼ごっこゲーム。ブラウザだけで動く、友達と遊べるP2Pオンラインゲーム。

## 🎮 遊び方
- **5人対戦**: 👹人狼(鬼)×1 / 🃏裏切り者×1 / 🏃逃げ×3
- **人狼**: 制限時間内に逃げを全員捕まえると勝利
- **逃げ**: 時間切れまで1人でも生き残れば勝利。捕まった仲間は牢屋で救出可能
- **裏切り者**: 見た目は逃げ、中身は人狼の味方。シグナルで逃げの位置を密告

## 🕹 操作
- **PC**: WASD移動 / マウスドラッグ視点 / Shiftダッシュ / E or クリックでアイテム
- **スマホ(横画面)**: 左スティック移動 / 右スワイプ視点 / タッチボタン

## 🛠 技術
- Three.js (3D描画・プロシージャル生成アニメ付きキャラクター)
- PeerJS (P2Pマルチプレイ・サーバー不要)
- A*経路探索 + FSM AIボット
- GitHub Pages 静的ホスティングで動作

## 🚀 ホスティング
GitHub Pages を有効化するだけで動きます (Settings → Pages → main branch)。
