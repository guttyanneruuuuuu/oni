# 人狼鬼ごっこ - Werewolf Tag 3D Evolution\n\n**究極の非対称型マルチプレイヤー鬼ごっこゲーム**\n\n3D非対称型マルチプレイヤー鬼ごっこゲーム。ブラウザだけで動く、友達と遊べるP2Pオンラインゲーム。脱獄鬼ごっこなどの競合に勝つために、複数のゲームモード、豊富なカスタマイズ、本格的な進行システムを搭載。\n\n## 🎮 ゲームモード\n\n### 古典モード（Classic）\n- **5人対戦**: 👹人狼(鬼)×1 / 🃏裏切り者×1 / 🏃逃げ×3\n- **人狼**: 制限時間内に逃げを全員捕まえると勝利\n- **逃げ**: 時間切れまで1人でも生き残れば勝利。捕まった仲間は牢屋で救出可能\n- **裏切り者**: 見た目は逃げ、中身は人狼の味方。シグナルで逃げの位置を密告\n\n### 脱獄モード（Escape）\n- 鍵を集めて脱獄ゲートから脱出\n- 鬼は逃げを全員捕まえるか、ゲートを封鎖する\n- **制限時間**: 6分\n- **必要な鍵**: 3個\n\n### サバイバルモード（Survival）\n- 時間経過でエリアが狭まる\n- 最後に生き残った者が勝利\n- **制限時間**: 7分\n- **ダメージゾーン**: ゾーン外で毎秒5ダメージ\n\n### チーム戦（Team Deathmatch）\n- 鬼チーム vs ランナーチーム\n- 一定時間内に相手チームを全滅させろ\n- **チーム構成**: 3 vs 3\n- **必要キル数**: 10\n\n### 王様は誰だ（King of the Hill）\n- マップ中央の王座を占領する\n- 最も長く座っていた者が勝利\n- **占領時間**: 60秒\n\n### インフェクテッド（Infected）\n- 1人の鬼から始まる\n- 捕まると鬼に変身\n- 最後のランナーが勝利\n\n## 🎯 主な機能\n\n### コアシステム\n- ✅ **高度なアクションシステム**: スライディング、壁キック、ドッジロール、レッジグラブ\n- ✅ **ビルドシステム**: 試合前にパーク（スキル）を自由に組み合わせ\n- ✅ **動的マップ**: 隠れ場所、インタラクティブなギミック、破壊可能なオブジェクト、高低差\n- ✅ **豊富なアイテム**: ランナー向け6種類、鬼向け3種類\n\n### カスタマイズ\n- 👗 **20+個のスキン**: ランナー・鬼・裏切り者向けの多様なデザイン\n- ✨ **エフェクトパック**: 足音、攻撃エフェクトのカスタマイズ\n- 😂 **エモート**: 試合中に使用できるジェスチャー\n\n### 進行システム\n- 🏆 **レベルシステム**: XP獲得でレベルアップ、報酬獲得\n- 🎖️ **アチーブメント**: 30+個の実績を解放\n- 📊 **ランキングシステム**: グローバル・シーズン・モード別ランキング\n- 🎯 **バトルパス**: 50ティアのシーズンパス\n\n### 収益化\n- 💎 **ガチャシステム**: スキン・エフェクト・エモートガチャ\n- 🛍️ **ショップ**: スターターパック、プレミアムバンドル\n- 💰 **2種類の通貨**: 通常コイン（ゲーム内獲得）、プレミアムコイン（課金）\n\n## 🕹 操作\n\n### PC\n- **WASD**: 移動\n- **マウスドラッグ**: 視点操作\n- **Shift**: ダッシュ\n- **E**: アイテム使用\n- **クリック / Space**: 攻撃・窓越え\n- **C**: クラウチ（ステルス）\n\n### スマホ（横画面）\n- **左スティック**: 移動\n- **右スワイプ**: 視点操作\n- **タッチボタン**: 各種アクション\n\n## 🛠 技術スタック\n\n### フロントエンド\n- **Three.js**: 3D描画・プロシージャル生成アニメ付きキャラクター\n- **PeerJS**: P2Pマルチプレイ・サーバー不要\n- **Canvas API**: ミニマップ・UI描画\n\n### ゲームロジック\n- **A*経路探索**: AIボット\n- **FSM**: ボットの状態管理\n- **物理演算**: 衝突判定、移動計算\n\n### データ永続化\n- **LocalStorage**: ユーザーデータ、進行状況、カスタマイズ\n- **IndexedDB**: 大容量データ（今後実装予定）\n\n### ホスティング\n- **GitHub Pages**: 静的ホスティング\n- **P2P通信**: サーバー不要\n\n## 🚀 クイックスタート\n\n### 1. リポジトリをクローン\n```bash\ngit clone https://github.com/guttyanneruuuuuu/oni.git\ncd
